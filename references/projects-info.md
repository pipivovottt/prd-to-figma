## P01 · FinEAM

### 页面框架

```
左侧固定侧边导航（含分组导航菜单，底部有收起导航按钮）
+ 右侧垂直布局：
    顶部固定多页签栏（多标签页导航栏 + 设置与用户菜单等功能区域）
    + 内容区（对应当前激活标签页的页面内容，垂直滚动）
```

**补充说明：**
- 侧边栏导航按业务模块分组，每组可展开/折叠，当前激活项高亮
- 页面内容区对应当前激活的标签页，切换标签即切换内容区内容
